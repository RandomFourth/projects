Market price is TCGplayer's figure from recent sales, grouped by week (every 3 days in the 1M and 3M views). Change compares the first and last point in the selected range. Prices update automatically every 6 hours, or right away with Refresh prices. This page checks for new data every 15 minutes and whenever you open it. Refresh button settings

Set up the Refresh button

The button asks GitHub to run the price update now. It needs a GitHub token, which is saved only in this browser on this device.

  1. Open GitHub's new token page and sign in.
  2. Give it a name. Under Repository access choose Only select repositories and pick projects.
  3. Under Permissions, add Actions and set it to Read and write. Nothing else is needed.
  4. Click Generate token, copy it, and paste it here.
